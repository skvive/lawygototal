# 운영 시스템 이식 가이드

1. 웹 루트 `pan.lawygo.com` 또는 `lawygo.com/pan`에 정적 사이트를 배포합니다.
2. `assets/integrations.js`의 Blogger feed / YouTube channel / 상담 API 값은 실서비스에서 별도 환경변수로 관리하는 백엔드와 연결합니다. 공개 JS에 토큰을 넣지 않습니다.
3. Blogger는 공식 피드 또는 승인된 RSS/Atom의 제목·URL·발행일·대표 이미지 데이터를 검증해 읽습니다. 저작권 준수와 출처 링크가 필요합니다.
4. YouTube는 YouTube Data API 또는 공식 iframe 임베드를 사용하고 각 영상의 권한·개인정보 관련 설정을 확인합니다.
5. 검색과 프로필은 검증된 변호사 등록 데이터로 교체하고, 실명·자격·소속 검증 절차를 적용합니다.
6. 문의는 개인정보와 민감사건 정보를 다루므로 HTTPS, 인증, 접근권한, 보관 기간, 삭제 요청, 전송 보호 설계를 거쳐 서버로 연결합니다. 현재 mailto 방식은 접수 성공을 보장하지 않습니다.
7. 구글 번역은 온라인 환경에서 외부 번역 모듈 동작·브라우저 쿠키 정책에 따라 달라집니다. 독립 KR·EN 작성 번역 데이터와 병행할 것을 권장합니다. 테스트된 전체 번역을 보장하지 않습니다.
8. 현재 결제 링크는 열지 않았으며, 실제 결제는 사전에 마련된 LEXID Stripe PR #14의 운영 검토·배포 완료 후 단계적으로 활성화해야 합니다.
