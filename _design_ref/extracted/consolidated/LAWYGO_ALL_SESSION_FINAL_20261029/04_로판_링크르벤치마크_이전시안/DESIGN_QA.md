# LAWYGO PAN 디자인·언어·기능 QA

## 1차 검토
- 샘플 카드의 별점·검증·성공률·후기를 제거해 오인 방지
- 검색 결과 개수는 실시간 필터링 결과만 표시
- 실제 접수되지 않는 문의는 `메일 초안 열기`로 명확히 명명
- Google Blogger/YouTube는 링크·허용된 임베드를 사용하고 무단 크롤링을 지양

## 2차 검토 예정 항목
- 각 HTML의 `title`, H1, 로컬 이미지 링크, 버튼/검색 폼에 누락 여부 확인
- 390px / 1440px의 오버플로 및 대표 페이지 스크린샷 점검
- 동적 검색 필터·언어 토글·로컬 채널 구성 검수
- 한국어 용어: `법률 콘텐츠`, `변호사 찾기`, `법무법인`, `상담 문의`, `법률정보`로 통일

## 주의
실제 로톡의 원본 스크린샷 전 페이지·로그인 영역까지 열람·복제한 결과물이 아닌, 공개적으로 확인 가능한 주요 메뉴와 페이지 유형을 바탕으로 한 독자 디자인입니다.

## 2차 개선 결과
- 서로 다른 생성 이미지로 가상 인물 프로필 중복 완화
- 콘텐츠 분야별 검색/분류 필터 추가
- 데스크톱/모바일 대표 상세페이지 캡처 및 JS 동작 재검증
- 한국어·영어 메뉴와 Google Translate 선택 방식 구분
