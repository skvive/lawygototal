## 새로운 브랜드 문법
- 네이비 #0c2439, 배경 아이보리 #f6f4ed, 골드 #c99c5c, 액션 블루 #176be5.
- 제목은 긴 문장을 최대 두 줄로 나누고, 카드 이미지는 5:3, 섹션은 2열/5열에서 모바일 1~2열로 반응형 전환.
- 마케팅 이미지의 모니터·UI는 **콘셉트 이미지**임을 명시. 공공 법원·변호사 인증 사실이나 고객 실적을 꾸며 넣지 않음.
- 로그인/결제/개인정보/법률 AI 관련 CTA는 실제 제공 범위와 작업환경을 명확히 고지. 비공개 프로젝트 코드는 공개 저장소에 복제하지 않음.

## PAN 데이터 파이프라인 (구현 및 운영 분리)
1. 기존 공개 RSS: `LAWYGO_PAN_BLOGGER_SITES`, `LAWYGO_PAN_YOUTUBE_CHANNEL_IDS` (운영자가 소유·이용 허용 범위를 확인한 출처).
2. 신규 API(선택): `LAWYGO_PAN_YOUTUBE_API_KEY`; Blogger는 `LAWYGO_PAN_BLOGGER_API_KEY` + `LAWYGO_PAN_BLOGGER_IDS` 필요.
3. 공식 검색 API가 켜진 경우에만 '법률·변호사' 키워드 검색. 15분 캐시, 중복 URL 병합, 최신순 정렬, 조회할 수 없는 경우 실제 검색 완료로 표기하지 않음.
4. 검색된 외부 결과는 원본 썸네일·헤드라인·요약·출처 링크 중심. 본문/영상 무단 복제와 인증·선정 표시 금지.
5. 별도 검증: Shorts는 제목/설명에 명시된 Shorts 표식으로 구분; 영상 길이만으로 Shorts 판정하지 않음.
6. **현재 운영 프로젝트에는 PAN API 키가 등록되지 않은 상태**이므로 API 기반 동적 발견은 배포만으로 활성화되지 않음.
