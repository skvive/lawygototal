# LAWYGO 7개 안드로이드 모듈 전환 설계

## 설계 원칙

- **1 코드베이스 / 7 앱 빌드 변형**. 단, Play에는 동일 기능의 중복 앱을 대량 게시하지 않고, 주력 `suite` 앱 우선 등록을 권장합니다.
- 순수 Compose 네이티브 UI / Android SAF 파일 선택 / WorkManager 공개 뉴스 캐시 / Material 3 접근성 / 시스템 외부 브라우저 인텐트.
- `ApiClient`는 HTTPS 443만 허용, 세션 쿠키 메모리 보관(재시작 로그인), CSRF 토큰 검사, 리디렉션 차단, 인증 서버 바뀌면 쿠키 폐기.
- 네이티브 Google Credential Manager로 ID 토큰 발급. 서버에서 발급자·대상자·서명·만료·nonce와 Google 고유 `sub` 확인 후 기존 사용자에게만 연결. 실제 Google 실계정 검증은 별도.
- 공개 RSS/판/위키 정보의 읽기 전용 오프라인 캐시. **노트, PRO, 관리자, 미승인 게시글, 다른 사용자의 데이터는 영구 캐시에 저장하지 않음.**
- API 바인딩은 v6.1 독립 콘텐츠 엔진 기준. 기존 `shinkangteam/lawygo`의 Neon/Supabase 운영 DB를 직접 사용하지 않으며 운영용 통합 Gateway가 더 필요함.

## 서비스별 네이티브 기능 매핑

| 서비스 | 네이티브 화면 | 서버 API | 완료 상태 |
|---|---|---|---|
| 저널 | 활자형 뉴스 카드, 원문 외부 열기, 오프라인 | GET /api/journal/news | 로컬 서버 계약 확인 |
| 채널 | 영상/칼럼 피드, 글 작성·수정, 승인/삭제 | /api/posts, /api/boards | CRUD 확인 |
| 판 | 변호사 콘텐츠 피드, 광고 표시, 카테고리 로컬 필터 | /api/growth/feed | 목록·표시 확인 |
| 위키 | 전문검색, 검수 공개 항목 | /api/wiki/search | 검색 계약 확인 |
| 노트 | 비공개 노트, SAF PDF/이미지, AI 동의·분석 | /api/posts, /api/media, /api/note/* | 데이터 격리 확인, AI 실키 미검증 |
| 프로 | 네이티브 안내, 기존 서버 열기 | 기존 pro.lawygo.com | **기능 1:1 포팅 미완료** |
| 허브 | 통계, 모듈 상태 변경 | /api/hub/* | 서버 계약 확인 |

## 다음 단계 — 실제 안드로이드 상용화

1. P0: Android Studio 실제 컴파일(7 변형 APK, AAB), UI 스크린샷 8~10장, Android 13~16 기기 3대 이상 및 태블릿 테스트.
2. P0: PRO 실제 로그인/사건/기일/서면 API와 기존 `site_users` 구독권한을 server gateway로 연결. 기존 SQLite 데모 데이터와 운영 DB 혼용 방지.
3. P0: 개인정보 처리방침 실제 URL, 탈퇴/삭제 링크, 법률광고 심의, 데이터 안전 양식, 장애·백업 복원 검증.
4. P1: Android 공식 법령·판례 검색과 AI 출처형 노트 1:1 연동, 디지털 서명, 푸시 FCM, 네트워크/배터리/메모리 프로파일링.
5. P1: Google 실계정 OAuth, Blogger·YouTube 개인 권한 승인 테스트, RSS 네트워크 오류 재현, Stripe/Play Billing 정책검토.
6. P2: Google Play 내부 테스트 → 비공개 테스트 → 스토어 심사 → 단계적 출시. 실제 콘솔 및 업로드키 승인 필요.

## 페이지 검증 매트릭스

모든 페이지: 세로/가로, 작은 폰(360x800), 대형 폰(412x915), 태블릿(800x1280), 큰 글꼴 1.3x, TalkBack, 고대비, 오프라인, 401/403/409/500, 앱 백그라운드/복귀, 화면 회전 상태복원 검사.

- 홈: 앱별 출발 탭, 7개 서비스 경로, 로그아웃, 설정.
- 저널: RSS 없을 때 빈 상태, 영문 제목, 링크 브라우저, 6시간 공개 캐시.
- 판: 광고 표기, 카테고리 필터, 유튜브 외부 앱 링크, 미승인 게시물 숨김.
- 위키: 검색어 최소 2자, 검색 결과 0건, 오래된 법령 경고.
- 노트: 계정 간 격리, 6MB 파일 제한/타입 검증, AI 명시적 전송 동의.
- 관리자: 관리자만 수정 허용, 동시 편집 충돌 409, 모듈 비활성 시 글쓰기 차단.
- PRO: 현 버전에서는 기존 PRO 링크 연결만 제공; 1:1 완료 판정 금지.
